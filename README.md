# ThreatLens AI 🔍
### Explainable Cybersecurity Threat Detection & Phishing Analysis

ThreatLens AI is a cybersecurity awareness and threat analysis platform designed to help users identify suspicious URLs and potentially malicious messages through explainable risk scoring.

The project demonstrates how cybersecurity principles, threat indicators, and automated analysis can work together to make digital environments safer.

## 🚀 Features

- **URL Threat Analysis:** Examine URLs for suspicious patterns and potentially dangerous indicators.
- **Phishing Message Analysis:** Identify warning signs commonly associated with phishing attempts.
- **Explainable Risk Scoring:** Generate a risk score from 0–100 with an understandable assessment.
- **Threat Indicators:** Highlight suspicious characteristics contributing to the analysis.
- **Security Recommendations:** Provide actionable guidance based on detected warning signs.
- **Scan History:** Store previous analyses locally using browser LocalStorage.
- **Report Export:** Copy or download analysis results for further review.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Cybersecurity threat analysis concepts

## 🔐 Security Notice

ThreatLens AI is an educational cybersecurity project and should not be treated as a replacement for professional antivirus software, commercial threat intelligence services, or security investigations.

Risk scores are heuristic assessments, not guarantees that a URL or message is safe or malicious.

Avoid submitting sensitive personal information or confidential messages.
